내보내기

.zip 하나에 원본 오디오, 무음 제거된 WAV, 원본을 컷 지점마다 클립으로 나눠 참조하는 XML 시퀀스, 사용법 메모가 함께 담깁니다 — 압축을 풀면 원본과 XML이 같은 폴더에 있고 XML이 상대 경로로 참조하므로, 다른 컴퓨터에서도 따로 찾아 연결할 필요 없이 바로 열립니다. (한글·공백이 든 파일명은 프리미어가 경로를 해석하지 못해 source.mp3 같은 이름으로 바꿔 담습니다 — 내용은 원본 그대로입니다.)

XML은 원본 오디오를 컷 지점마다 클립으로 나눠 참조하고, 경로는 같은 폴더 기준 상대 경로로 적습니다. zip을 푼 폴더 그대로 두고 프리미어에서 File → Import로 XML을 열면 어느 컴퓨터에서든 미디어 찾기 없이 바로 열립니다. 두 파일을 떼어놓거나 오디오 파일명을 바꾸면 연결이 끊어집니다.
